# tb4_nav_patrol - Nav2 Patrol & Simulation

## Mô tả module

Module này chịu trách nhiệm:
- Cấu hình Navigation2 (Nav2) cho TurtleBot 4 Lite
- Thiết lập hành vi tuần tra tự động
- Quản lý map và localization
- Cung cấp launch file cho mô phỏng

## Cấu trúc thư mục

```
tb4_nav_patrol/
├── launch/          # Launch files
├── config/          # NAV2 config files, map files
├── scripts/         # Python scripts for patrol logic
└── README.md        # Tài liệu module
```
